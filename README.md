# Family Kitchen

A mobile-first family recipe app designed around:

- quick, practical recipes for a UK family kitchen
- low fresh-food waste and common supermarket pack sizes
- quick steps for confident cooks, with full methods underneath
- wholemeal pasta by default
- tinned beans/lentils as the quick default, with dried-pulse prep as an optional variation
- good use of frozen peas, sweetcorn, broccoli and cauliflower
- optional pressure-cooker methods
- two-drawer air-fryer timings where useful

## Initial meal set

- Beef & mixed bean chilli
- Mild family curry
- Lentil-boosted spaghetti bolognese
- Fish / salmon air-fryer traybake
- Burritos
- Greek chicken & potatoes
- Sausages with wedges or mash
- Beef & lentil keema
- Pesto wholemeal pasta bake
- Pizza night (summer)
- Stew with dumplings (winter)
- Tuna wholemeal pasta bake

## Development

npm install

```

```
